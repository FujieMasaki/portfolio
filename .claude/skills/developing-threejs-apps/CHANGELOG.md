# Changelog

## 1.0.0

- Initial public release of the “developing-threejs-apps” Skill.
- Repo-first workflow: detect Three.js revision, bundler/framework conventions, and render-loop ownership before editing.
- Strong lifecycle contract: init/resize/loop/teardown patterns with disposal requirements.
- Separate deep references for color, postprocessing, glTF assets, performance/memory, shaders, and WebGPU adoption.
- Optional deterministic audit scripts for repo patterns and asset sizing.
