# 観点: セキュリティ 🔴

このサイトはNext.js（App Router）で配信する公開のポートフォリオで、ログインや訪問者のデータの保存はない。
クライアントへ届くコード・値は誰でも取得できる前提で扱う。

## 1. 秘密情報と設定 🔴

- [ ] APIキー、アクセストークン、パスワード、秘密鍵、内部専用URLがソースコード・
  コミット対象ファイルにハードコードされていないか。
- [ ] `NEXT_PUBLIC_` prefix の環境変数に秘密情報を入れていないか。Next.js はこれらをクライアント
  バンドルへ埋め込む。
- [ ] `.env`、`.env.local`、秘密鍵ファイル、実運用の設定値が差分に含まれていないか。
- [ ] 依存追加、CI設定、GitHub Actions の変更で、トークンをログ出力・第三者スクリプト・
  不要な権限へ渡していないか。Actionsは`permissions`を最小にし、第三者のactionはcommit SHAで固定しているか。

## 2. 計測と外部スクリプト 🔴

- [ ] 計測（GTM・GA4・Clarity）を足す・変えるとき、送る情報が増えていないか。URLのquery・入力値・
  メールアドレスなど、訪問者を特定できる値を送っていないか。
- [ ] GTMのIDが未設定の環境（ローカル開発・preview）で計測しない既存の振る舞いを保っているか。
- [ ] 新しい外部スクリプト・iframe・フォントを読み込む場合、必要性、提供元の信頼性、送られる情報を確認したか。

## 3. 外部入力・表示・遷移 🟠

- [ ] `dangerouslySetInnerHTML` を使う場合、内容が自分で書いた固定の文字列だけか。外部・URL由来の値を
  HTML として解釈させていないか。
- [ ] 外部リンクを`target="_blank"`で開く場合、`rel="noopener noreferrer"`を付けているか。
- [ ] URLのqueryなど外部から決められる値を`href`・`src`・リダイレクトに使っていないか。使う場合は、
  `javascript:` などの危険なスキームと open redirect を防いでいるか。

## 4. 公開する情報 🟠

- [ ] 公開してよい個人情報だけを載せているか（連絡先・経歴・写真）。画像のEXIF（位置情報）が残っていないか。
- [ ] 下書き・参考画像（`references/`等）など、公開を意図しないファイルを`public/`に置いていないか。
  `public/`のファイルはすべてURLで取得できる。
